# WA Планировщик

Android-приложение для отправки сообщений в WhatsApp по расписанию через ваш телефон и официальный WhatsApp.
Отправка полностью автоматическая: в нужное время приложение само открывает чат и нажимает «Отправить».

## Что умеет

- Отправка на любой номер: вводится вручную или выбирается из контактов.
- Разовая отправка или повтор: каждый день, по будням, каждую неделю.
- Обычный WhatsApp или WhatsApp Business.
- Несколько сообщений на одно время отправляются по очереди.
- После перезагрузки телефона расписание восстанавливается само.
- По каждой отправке приходит уведомление с результатом, и он же показывается в списке.

## Как получить APK (без установки программ)

1. Зарегистрируйтесь на github.com, это бесплатно.
2. Создайте новый репозиторий: **New repository** → любое имя → **Create**.
3. Нажмите **uploading an existing file** и перетащите **всё содержимое** папки `WaScheduler`, включая скрытую папку `.github`.
   - Скрытая папка может не перетащиться. Тогда создайте файл вручную: **Add file → Create new file**, имя `.github/workflows/build.yml`, а содержимое скопируйте из одноимённого файла в архиве.
4. Откройте вкладку **Actions**. Сборка займёт 3–5 минут, после неё появится зелёная галочка.
5. Откройте сборку и внизу, в разделе **Artifacts**, скачайте **WaScheduler-apk**. Внутри zip-архива лежит `app-debug.apk`.

Второй способ: откройте папку в **Android Studio** и выберите **Build → Build APK(s)**.

## Установка и настройка на телефоне

1. Скопируйте `app-debug.apk` на телефон и откройте его. Разрешите установку из этого источника.
2. Откройте **WA Планировщик**. Вверху показано, что ещё осталось настроить:
   - **Включить автоотправку** → в «Спец. возможностях» найдите «WA Планировщик» и включите.
     На Android 13 и новее переключатель может быть серым. Тогда: Настройки → Приложения → WA Планировщик → ⋮ (вверху справа) → **«Разрешить ограниченные настройки»**, и после этого включите снова.
   - **Разрешить работу в фоне** → «Разрешить».
3. Разрешите уведомления.
4. **PIN экрана.** Если на телефоне стоит PIN, нажмите в приложении **«🔒 Указать PIN экрана»**. В момент отправки приложение само введёт PIN, отправит сообщение и снова заблокирует телефон.
   Работает только с цифровым PIN, а не с графическим ключом или паролем из букв. PIN хранится только на телефоне в зашифрованном виде (Android Keystore). Если PIN не подошёл, приложение делает не больше двух попыток, чтобы телефон не заблокировался.
5. **Xiaomi / Redmi / POCO:** Настройки → Приложения → WA Планировщик → включите **Автозапуск**, а в «Контроль активности» выберите **Нет ограничений**.
   **Samsung:** Обслуживание устройства → Батарея → Ограничения → добавьте приложение в **«Неспящие приложения»**.
   **Huawei / Honor:** Батарея → Запуск приложений → WA Планировщик → управлять вручную, включить всё.

## Проверка

Создайте сообщение себе или знакомому и нажмите **«Сохранить и отправить сейчас (проверка)»**.
WhatsApp откроется, сообщение отправится само, и телефон вернётся на рабочий стол.

## Как это работает

- В нужное время срабатывает точный будильник Android (`setAlarmClock`). Он работает даже в режиме энергосбережения.
- Приложение включает экран и открывает чат через официальную ссылку `whatsapp://send?phone=…&text=…`. Текст уже вставлен в поле ввода.
- Служба специальных возможностей проверяет, что в поле ввода именно ваш текст, и нажимает «Отправить».
  Служба реагирует только на окна WhatsApp и только в момент отправки. Данные никуда не передаются.
- Если экран был выключен, после отправки телефон снова блокируется (Android 9+).

## Ограничения

- Отправка идёт только на номера. В группы этот вариант пока не отправляет.
- Номер должен быть зарегистрирован в WhatsApp, иначе через 45 секунд придёт сообщение об ошибке.
- Если WhatsApp сильно изменит интерфейс в обновлении, кнопку может быть не найти. Служба ищет её по id `send` и по подписи «Отправить» / «Send».
- Не используйте приложение для массовых рассылок незнакомым людям: WhatsApp блокирует за спам. Отправка своим контактам безопасна.
